# Hex Tactics

Turn-based isometric hex tactics prototype (medieval swordsmen, PvP over a direct connection).

Play: https://twiceswords.github.io/hex-tactics/

- Left-click: select · Right-click: move / attack · Tab: next unit · Space: end turn early · R twice: new game
- Online: one player clicks **Host game** and shares the code, the other enters it and clicks **Join**.
